# Mathcraft

> **MathCraft: Visual Geometry & Interactive Mathematics**

MathCraft is an interactive mathematics visualization platform and Android application built with React, TypeScript, Tailwind CSS, and Capacitor. It brings abstract geometric, trigonometric, and calculus theorems to life with real-time interactive canvases, touch gestures, and interactive visual proofs.

## ✨ Features

- **Interactive Geometry Engine**: Dynamic construction of points, segments, circles, perpendiculars, medians, tangents, angles, and polygons.
- **Visual Proofs**:
  - Circle Area Proof (Wedge unwrapping to rectangle)
  - Pythagoras Liquid/Visual Proof
  - Triangle Angle Fold Proof
- **Calculus & Trigonometry Viewports**: Dynamic function plotting, secant-to-tangent limits, Riemann sums, unit circle trigonometry, and Lissajous curves.
- **Audio Synthesis**: Mathematical sound synthesis mapping geometry to audio frequencies.
- **Cross-Platform**: Modern web application with responsive UI and native Android support via Capacitor.

## 🚀 Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- [npm](https://www.npmjs.com/)

### Installation

```bash
git clone https://github.com/ssilu07/Mathcraft.git
cd Mathcraft
npm install
```

### Development Server

Run the development server locally:

```bash
npm run dev
```

### Production Build

Create an optimized web production bundle:

```bash
npm run build
```

### Android Build (Capacitor)

Sync web assets with the Capacitor Android project:

```bash
npx cap sync android
```

Open the Android project in Android Studio:

```bash
npx cap open android
```
